# Cue Studio

一个 LLM 驱动的教师代理（teaching agent）。它的媒介不是幻灯片，而是一块无界的二维舞台平面（backstage）和一架摄影机 —— 知识被**演**出来，不是被列出来。

与常见的 AI artifact 不同，它**不是编译型，而是解释型**：模型每次调用只发出一条 `op`（"说这句话，12 秒"、"把这支向量放到板上"、"镜头推到箭头尖"），追加进一条**只增不删的日志**；解释器把日志演化成舞台 —— 道具表、时钟、镜头轨迹、门（gate）。成品不存在，只有过程。于是一堂课 = 一段磁带：分享（日志 deflate 进 URL）、重放、从任意一拍截断重排，全都是日志的副产品，没有一个单独实现。

## 功能特性

- **双角色编排**：导演（`src/tools/director.ts`，21 个动词）负责编排整场演出；美工（PAINTER）只画图不说话，产出一个内联 `<svg>`，逐笔长在舞台上。两条路径共用同一个 `Teacher.ask()`，限流退避一视同仁。
- **五张交互卡**：`quiz`（认选项）、`probe`（点台上那个形状）、`dial`（拨一个数，按距离判）、`type`（打一句话，按必须出现的词判）、`drag`（亲手把道具搬到该在的位置，按距离判）—— 全部停表判分、作答落带可重放、按 `concept` 记反复错过。
- **学习者出口**：「我不会 · 换个讲法」「这道先跳过」逃生门（判分认这两句、不进档案）；`offer` 按钮门（导演替他开口，按下后的话与亲手打出来一模一样）；**指着问**（学习者在台上指一处、写问题，指认是学习者状态，不停表不判分）。
- **3D 是数据，不是代码**：`scene3d` 是一份声明式图元表（box / sphere / cylinder / cone / torus / plane / line / arrow + camera / spin / grid / axes），由自己的解释器编译成 three.js 对象，入参过白名单；它只是二维板上的一扇内嵌窗，能进日志、能分享、能重放。
- **公式是排版的，不是手画的**：道具 markup 里任何带 `class="tex"` 的元素，其 LaTeX 内容由 KaTeX 排成 MathML，浏览器自己完成排版 —— 真分数、根号、下标、矩阵，零样式注入。
- **账目条**：`第 3/7 拍 · 正在讲：向量加法 · 问 3 · 对 2 · 错 0 · 跳过 1 · 12,480 tokens · $0.0034` 常驻台上，从 `compiled` 纯派生，不重开一炉。
- **动效纪律**：一屏只讲一件事、镜头必须有理由、每一句旁白只承担一个动作；`motion` 的位移是舞台时间的纯函数（cue 一结束道具回到锚点），覆盖层不推进时间。
- **安全模型**：模型只能交 markup，不能交代码 —— DOMPurify 白名单 + shadow root 作用域隔离 + 磁带白名单（`guard`），分享链接（`#s=`）与工具调用共用同一道门。

## 快速开始

```bash
npm install
npm run dev    # http://localhost:5173
```

**排练模式（不花一个 token）**：只在 `npm run dev` 下出现 —— 配置抽屉顶部有一个「本地排练模式（不联网，用固定谱子驱动同一套舞台）」勾选，勾上即走 pi-ai 的 faux provider（进程内 yield 一份固定谱子：向量加法 / 力的分解）。生产构建里这个勾根本不渲染。引擎语义、运镜、转场、gate、打断回卷、录像重放都在这一层验证。

**接真模型**：打开配置抽屉的「模型接入」，加一个 provider。支持两种形状：`openai-completions`（OpenAI 兼容 `/chat/completions`）和 `anthropic-messages`。密钥存在 `localStorage`（`canvas-teacher.credential.<id>`），配置行为 `canvas-teacher.llm`。「拉取模型列表」读的是提供商的 `/models` —— 中转站不答这一问不是死路：点「+ 手填一个模型」直接写模型 id 与显示名。

> 纯浏览器直连、无后端网关、无账号 —— 所以 key 在 DevTools 里可见。这是已接受的架构代价，不是 bug。旁白用浏览器自己的 `speechSynthesis`，不接外部 TTS 服务。

## 核心概念

### 词汇表

代码、提示词、UI 用的是同一套词，没有第二套命名。

| 词 | 是什么 |
| --- | --- |
| backstage | 无界二维平面。一场戏约 1600×900 单位，场景之间相隔 2000~3000。**一块被命名过的板就有位置**，哪怕它还是空的 |
| prop 道具 | 平面上有身份的对象。**id 跨场景持续** —— 第三幕那个箭头仍然是第一幕那一个 |
| revision | 同一道具的一次外观变更，带自己的 `box` 和一段窗口 `[t, off)` |
| cue | 一次工具调用 = 一个 cue，落在舞台时间轴上 |
| beat | 刻意的静默，让画面自己站住 |
| gate | 停时钟等学习者的地方：`ask_learner` / `point_at` / `tune` / `type` / `drag` / `pause_for` |
| tape | 日志本身，可导出、可分享、可重演 |

学习者也是台上的人：他说的话（`answer`）作为 op 落在磁带上，只记内容和他答的是哪张卡，**不占时钟**。分享出去的录像带着他答错的那句话（那是一堂课里最值钱的上下文）；重放知道哪些卡已经答过。配套的决定：**录像不再向看的人重新提问** —— `live=false` 时 `currentGate()` 恒为 null，点开链接的人是来看的。

### 时间规则

- 只有 `narrate` / `beat` / `transition` **占时钟**；`camera` / `highlight` / `motion` 是叠在旁白之上的覆盖层，不推进时间，到点就走、不留痕。
- **时钟不许跑在画面前面**：首次演出时，镜头框住一个还没有任何图形的空框、而它的 `paint` 正在进行时，`tick()` 不推进 `t` —— 美工开始流式吐线的那一刻放行（3b1b 的节奏是"边画边讲"）。
- **时钟也不许跑在没有观众的房间里**：隐藏标签页的 rAF 被浏览器 throttled 成一秒一格，所以 `visibilitychange` 一到就停住时钟，回到前台自己接上；学习者按下的暂停不会被替它续上。

## 项目结构

```
src/engine/   日志、解释器、编译、相机、运动、旁白时钟、分享、3D 解释器、公式排版、舞台渲染、磁带白名单（guard）
src/agent/    主循环、上下文预算、提示词、学习者档案、排练谱子
src/tools/    导演工具面（动词 schema；入参白名单在 engine/guard，两条进门的路共用）
src/llm/      传输适配（两种 api 形状、凭据存储、限流退避）
src/ui/       模型配置、节拍条、学习者档案
```

## 验证分三层

别拿 fixture 的绿灯当服务商链路的绿灯。

1. **排练模式（faux）**：只证明"我自己的代码自洽"。
2. **mock OpenAI 兼容服务**（`scripts/mock-openai.mjs`，自己的 Node 进程）：验传输适配器形状。开关：`MOCK_PORT`、`MOCK_HOLD=<ms>`、`MOCK_429=<role>:<N>`、话题里写 `MOCK-TRUNC-N`。
3. **真实服务商**：端到端跑完整堂课才算证。

双端对账是唯一免疫观察通道污染的办法：mock 的 stdout 记"发出了几条什么形状"，页面 transcript 记"收到几条 / 推了几条 nudge"，两边对上才算。服务商限流通常是 tokens-per-minute，单场长课能吃到十几万 tokens —— 测完一轮要算代价，别为验证反复开真课。

## 已知边界

- 密钥在 localStorage，DevTools 可见（见上）。
- 3D 的拖动角度、指着问的那一点不进分享链接（设计决定：那是学习者状态，不是演出）；分享出去的是导演随后用 `camera` 落下的那一刀，或者他发出去的那句原话。
- `guardOp` 兜解释器会算错的**量**（数字、枚举、时长、坐标、长度、数量上限），不兜整卷的总量与语义：每帧的可见道具数、DOM 节点数不在门上封顶；一段把三板堆在同一个坐标上的带照样能过门。
- 账本那一道（`guardEntry`）认不出来的号是**丢掉**，不是补一个 —— 号不许重编；`track` 认不出来时给 `"*"` 而非 `main`，那一句会排在台上、参与编译，但没有轨道演它。
- 仓库里留了几条**毫秒**门，只在机器空着时准（全套并行跑时基线自己也会偶发红）；行为与格子的门才是可依赖的那一层。
